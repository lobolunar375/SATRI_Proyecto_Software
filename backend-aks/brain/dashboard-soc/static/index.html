SATRI Fase 4 — Kernel-Mode Protection (Ring 0)
Agentes con el driver SatriDriver.sys activo. Protección a nivel de kernel del sistema operativo.
ARQUITECTURA
Ring 3 ↔ Ring 0
🔒 Process Blocking
✅ Activo
Intercepta la creación de procesos en Ring 0 mediante PsSetCreateProcessNotifyRoutineEx. Bloqueo atómico antes de que el proceso llegue a user-space.
📋 Kernel Event Buffer
✅ Activo
Buffer circular de 256 eventos en memoria no paginada. Transferencia eficiente vía IOCTL_SATRI_GET_EVENTS al agente Python.
⚡ IOCTLs Disponibles
0x800 GET_EVENTS
0x801 BLOCK_PID
0x802 SET_BLOCKLIST
0x803 GET_STATS
